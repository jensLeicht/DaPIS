# The Data Protection Icon Set (DaPIS) v3+

This set of privacy icons represents an extended and enhanced version of the [DaPIS v3](https://doi.org/10.5281/zenodo.7182819) icon set.

We added 64 new icons to the set and reformatted and resized the existing 42 icons.
You can find a list of modifications in modifications.txt and a list of additions in additions.txt.

This extension of the icon set was created as part of the developoment of the PriPoCoG (Privacy Policy Compliance Guidance framework) privacy policy interface, published [here](https://github.com/jensLeicht/PrivacyPolicyInterface).
The research that went into the development of that interface is published in the following paper:

`Leicht Jens and Lukasewycz Julien and Heisel Maritta, (2025), "PriPoCoG: Empowering End-Users’ Data Protection Decisions", In Proceedings of the 27th International Conference on Enterprise Information Systems - Volume 2, ISBN 978-989-758-749-8, ISSN 2184-4992, pages 673-684`
